O que é um embedding?

Um embedding é uma representação numérica de um item. Uma palavra, uma frase ou um documento vira um vetor com muitas dimensões, por exemplo [0,82, 0,18, 0,47]. O modelo aprende posições em que itens usados em contextos parecidos tendem a ficar próximos.

O vetor não é a palavra nem uma definição de dicionário: é um conjunto de números que registra relações aprendidas pelo modelo.

O que são estes grupos?

Nesta amostra, cada ponto é uma palavra. Os 30 pontos foram organizados didaticamente em três grupos: Animais, Tecnologia e Natureza.

O grupo é um metadado: uma informação usada para colorir e comparar os pontos. Ele não foi descoberto automaticamente pelo gráfico. Em um conjunto real, cada ponto também poderia representar um documento, imagem, usuário ou outro objeto.

Palavra ≠ documento
Um documento pode gerar um único vetor ou vários vetores, dependendo do modelo. Aqui usamos palavras curtas para tornar a leitura dos grupos mais fácil.

Por que o gráfico tem só 2D ou 3D?

Um vetor real pode ter centenas de dimensões, mas uma tela só consegue mostrar duas ou três. Uma projeção reduz as dimensões para criar um mapa aproximado.

PCA
procura eixos lineares que preservam o máximo possível da variância global.
t-SNE
prioriza a vizinhança local; grupos podem aparecer separados mesmo quando as distâncias globais ficam distorcidas.
UMAP
tenta preservar relações locais e alguma estrutura global, também produzindo uma aproximação.

Trocar o método pode mudar a posição e a distância aparente dos pontos sem mudar os vetores originais.

Como interpretar o mapa?

  1. Proximidade: pontos próximos na projeção podem ter representações semelhantes, mas confirme o método e a escala.
  2. Grupo: uma cor mostra um metadado, não prova que o modelo aprendeu três categorias perfeitas.
  3. Vizinhos: a lista à direita calcula uma distância entre os vetores da amostra e ajuda a investigar cada ponto.
  4. Rótulo: buscar “gato” apenas destaca o ponto; não altera o embedding nem treina o modelo.
Regra de ouro
Uma imagem bonita de clusters é uma hipótese para investigar, não uma prova de significado.

O que cada controle faz?

Colorir por Grupo usa o metadado da amostra. Distância ao selecionado cria uma escala de cor a partir do ponto ativo. 2D/3D muda a quantidade de eixos exibidos. A busca, os rótulos e a grade alteram apenas a visualização.

O botão de arquivo aceita uma linha por item, com o rótulo na primeira coluna e números separados por vírgula ou tabulação nas colunas seguintes.

Limites desta demonstração

Os dados que acompanham esta página são locais e didáticos. Os vetores são gerados para demonstrar navegação; nenhum modelo de linguagem externo é executado no navegador. Por isso, os grupos não representam uma medição científica e as opções t-SNE/UMAP são aproximações visuais.
