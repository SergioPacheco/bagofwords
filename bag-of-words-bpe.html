    Frequência dos termos

    Compare os termos mais usados com os de maior peso TF-IDF. O gráfico tem uma escala própria para cada seleção; compare os valores exibidos nas barras.

    TF-IDF = frequência bruta × [ln((1 + documentos)/(1 + documentos com o termo)) + 1]. No conjunto, somamos os pesos dos documentos. Mesmo ao selecionar um documento, o IDF usa o conjunto inteiro.

    N-gramas: um pouco da ordem

    Tokenização BPE — O modelo não lê letras

    Os modelos de linguagem não processam diretamente palavras como unidades de significado. O texto é convertido em tokens, que recebem identificadores numéricos e posteriormente são transformados em representações vetoriais.

    Texto → Símbolos iniciais → Aprendizado de pares → Tokens → IDs numéricos

    BPE educacional baseado em bytes UTF-8, treinado aqui no navegador. As divisões e os IDs dependem deste corpus e dos merges. Não reproduzem os tokenizadores completos de GPT, Qwen ou outros modelos. BPE, sozinho, não compreende significado; IDs não são embeddings.

    1

    Corpus e pré-tokenização

    O texto de treino é dividido em palavras apenas para explicar a entrada. O BPE começa com os bytes e aprende os pares vizinhos observando o corpus.

    Ensine com um corpus

    Repetições influenciam os pares aprendidos. Limite: 16.000 bytes UTF-8. Alterou o corpus? Treine novamente.

    2

    Contar pares adjacentes

    Para cada palavra, contamos os pares de símbolos vizinhos. O par mais frequente é o candidato ao próximo merge; em caso de empate, a ordem dos IDs decide.

    Aprendizado de pares

    Começamos com os 256 bytes possíveis: IDs de 0 a 255. Cada merge cria um símbolo com ID a partir de 256. A frequência é recalculada após cada união. Empates usam os menores IDs do par. Não unimos através dos espaços: cada trecho sem espaços e cada caractere de espaço é um segmento independente.

    Vocabulário inicial: bytes observados neste corpus

    Os demais bytes também existem na base, mesmo com frequência zero: isso permite representar texto novo.

    Treinar aplica todos os merges aprendidos. Reiniciar volta à etapa 0; avance um merge por vez ou selecione uma linha. Na tabela, as setas movem o foco e Enter ou espaço seleciona a etapa.
